DEMO VALLE DE BRAVO - CANDIDATA LOCAL PARA REVISION

WINDOWS 10/11, 64 BITS
1. Copia y extrae el ZIP completo en una carpeta de la computadora.
2. Abre ABRIR_DEMO.cmd. Se abrira el navegador con una direccion 127.0.0.1.
3. Deja abierta la ventana del servidor y pulsa "Comenzar recorrido · 3 min".

No necesitas instalar Python, Node ni descargar datos. El paquete incluye Python
y su licencia. No abras sitio/index.html con doble clic: usa el lanzador.
Si no se abre el navegador, copia la direccion que muestra la ventana.
Para cerrar el servidor, vuelve a esa ventana y pulsa Ctrl+C.

PLAN DE RESPALDO
Los perfiles, las tres escalas incluidas, las fichas, los proyectos y el recorrido usan
archivos incluidos. Funcionan sin internet con el servidor local encendido.
Las calles externas, lluvia reciente, pronostico actualizado y enlaces a las
fuentes requieren internet. Una consulta anterior guardada tiene su propia fecha.
La primera apertura NO necesita una conexion externa ni una visita previa.

Si el navegador no puede dibujar el mapa, usa la busqueda de comunidades o la
lista de Prioridades. Como respaldo visual, abre RESPALDO_VISUAL.html o la guia
PDF. No presentes las capturas como una aplicacion interactiva.

MACOS / LINUX
El sitio compilado es portable. Con Python 3 instalado, abre una terminal en
esta carpeta y ejecuta: python3 iniciar_demo.py
No se incluye un runtime macOS y no se probo el lanzador en una Mac real.
ABRIR_DEMO_Mac.command es una comodidad y puede requerir permiso de ejecucion.

PERFILES Y PROYECTOS
Las vistas de gestion y consulta no son cuentas ni permisos de servidor.
Los tres proyectos iniciales y todos sus montos y mediciones son ficticios.
Los registros se guardan solo en este navegador y direccion local. Para llevar
registros a otro equipo, exporta JSON e importalo sin sobrescribir conflictos.
Las unidades de cuenca/microcuenca son modeladas HydroBASINS, no delimitaciones
oficiales mexicanas. El censo agregado sigue cubriendo solo Valle de Bravo.

Repositorio base y remoto comprobados en ea729f2ee9aed1112a0b5fbed50b35d8302e5797. Rama aislada mejoras-propuestas. El sitio publicado original se revisó en portada y mapa. La candidata se probó en su propia compilación local.

Qué se corrigió

  • Portada para computadora y móvil, navegación visible, jerarquía tipográfica, cartografía real en la introducción y recorrido de 2–3 minutos.
  • Mapa local por defecto, búsqueda de comunidades, caso de San Gabriel Ixtla, fichas amplias, cierre con Escape y contención del foco del teclado.
  • Se recuperaron los resultados de la base publicada que una ejecución parcial del agente había retirado. Se preservó el archivo parcial para auditoría.
  • Se corrigieron nueve textos de almacenamiento: ahora son preguntas de verificación e intervalos posibles. Se agregó el límite inferior y se validan faltantes y universos inválidos. El índice conserva su cota superior y sus resultados para evitar un cambio metodológico oculto.
  • Captación señalada como simulación: supuestos, unidades, descarte, meses con al menos 90 % de demanda simulada y advertencia de que no acredita potabilidad ni abasto.
  • Lluvia: se explican productos, periodos y áreas distintos; se evita atribuir causas. La ventana de 30 días ya no rellena faltantes con ceros ni días antiguos.
  • Se distinguieron funcionalidades existentes, prototipos y visión futura. Se retiraron de la demo las cifras nacionales no auditadas para esta entrega. El ejercicio de presupuesto quedó opcional, sin costos inventados.
  • Guion para Jimena, fases con dependencias y paquete local Windows con runtime incluido.

Lo que no se ha validado

  • Exactitud científica integral, situación actual en campo, consentimiento o representatividad de las comunidades y factibilidad de intervenciones.
  • Calidad del agua, potabilidad, suficiencia del almacenamiento, variación de techos, pérdidas, demanda real, obras, costos y mantenimiento.
  • Equivalencia entre lluvia reciente y ERA5; comparación de ERA5 1991–2020 en cabecera con Daymet 2004–2023 por localidades. No se ejecutó una comparación homogénea ni se estableció una causa.
  • Safari/macOS, teléfono físico, hardware de Jimena, auditoría completa de accesibilidad y un ensayo de presentación humano.
  • Actualización del sitio público: no se desplegó. El QR conserva la dirección del sitio original.

Cómo reproducir

En el repositorio: npm ci, npm run build, npm test y python -m pytest pipeline/tests -q. Servir dist por HTTP y ejecutar python scripts/qa_demo.py http://127.0.0.1:4173/ con Playwright/Chromium instalados. No es necesario ejecutar el pipeline de descargas para abrir esta candidata.

El paquete se crea con scripts/preparar_demo.py, usando un runtime CPython existente y conservando su licencia. No modifica el entorno del sistema.
